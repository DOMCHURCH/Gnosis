Settings

API keys

Every key in the file above, editable. The first two are always shown because Gnosis needs them; add any other your tools or MCP servers expect. Values are never sent to this window — a blank box means “leave it alone”, not “erase it”.

Voice — desktop app only

Say “hey jarvis” to talk to the agent. Not available in the browser UI or the CLI: the microphone lives in the desktop shell and is never exposed to the served page.

Wake-word detection uses openWakeWord — open source, runs locally, and needs no API key. Transcription uses the GROQ_API_KEY above.

Voice

Downloads openWakeWord (wake word) and Kokoro (speech), both free and fully local — about 330 MB of model weights. Needs Python 3.9+ with pip already on the machine; it will not install Python for you.

Working directory

The folder the app opens into. The agent reads, searches and edits from here, so point it at a project you actually work on — an empty folder means every question about “this project” finds nothing. Leave it blank to use the default.

Keyboard shortcuts

Active while a Gnosis window has focus.
